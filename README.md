自定义软件源
添加：
```bash
src/gz my_base https://hatbhtbh.github.io/opkg-repo/base
src/gz my_luci https://hatbhtbh.github.io/opkg-repo/luci
src/gz my_packages https://hatbhtbh.github.io/opkg-repo/packages
src/gz my_routing https://hatbhtbh.github.io/opkg-repo/routing
src/gz my_kmods https://hatbhtbh.github.io/opkg-repo/kmods
```
点击右下角的 “提交”（或保存）按钮。   
返回软件包列表页面，点击 “刷新列表”
